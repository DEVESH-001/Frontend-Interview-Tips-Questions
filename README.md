# Frontend-Interview-Tips-Questions

A curated collection of frontend interview questions, answers, and practical tips to help you prepare for your next web development interview.  Whether you're brushing up on HTML, CSS, JavaScript, React, or diving into system design and performance optimization, this repo aims to guide you through what really matters in frontend interviews.

## File structure

- Every Folder has a `readme.md` file that contains interview questions and answers related to that specific topic.
